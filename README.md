# Atlas

A Minecraft 1.8.9 Forge client.

> **Use it only where it is allowed**: single player, your own server, or a test server that permits such
> clients. Using it on servers that forbid it can get you banned.

Discord (downloads, help, bug reports, suggestions): **https://discord.gg/SNPC2TcM8v**

## Install

Download `Atlas-vX.Y.Z.jar` from [Releases](../../releases) and put it in the `mods` folder of a
Minecraft 1.8.9 Forge instance. Later versions install themselves (online updates are signed).

## Building

Requires JDK 17 to run Gradle (the mod itself targets Java 8).

```bash
./gradlew build
```

The jar is written to `build/libs/`.
